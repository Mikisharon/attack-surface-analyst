Attack Surface Analyst

Five agents turn one domain into a prioritized, evidence-backed exposure report. Code fetches the facts; the LLM reasons over them and never invents them.

Pipeline

    Evidence

    Responsible use. Scans run only on allowlisted targets: the author's own domain and sites that are intentionally public for security testing. Discovery is passive (certificate transparency), and each discovered host receives at most one ordinary HTTPS request. Page titles and headers from targets are shown as untrusted data.
